# XBoost (nama sementara)
Game booster berbasis Shizuku. Tanpa bubble/overlay.
- Menu utama: daftar game (tambah game sendiri), tap game = XBoost aktif, game langsung dibuka.
- Default aktif (bisa dimatikan di tab Pengaturan):
  - Mode performa: fixed performance mode + lock governor CPU/GPU ke performance (lock penuh hanya kalau Shizuku jalan sebagai root).
  - Bekukan semua app lain di semua user (termasuk clone / dual apps) + app sistem berikon launcher, kecuali yang diproteksi / whitelist.
  - Matikan animasi (dikembalikan saat stop).
  - Matikan notifikasi (mode senyap total + heads-up off, dikembalikan saat stop).
  - Optimasi game: Game Mode performance, thermal override, battery saver off, refresh rate maksimum.
- Berhenti: tombol "Stop & pulihkan" di notifikasi XBoost, tombol di app, atau otomatis saat game ditutup.
