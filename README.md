# XBoost (nama sementara)
Game booster berbasis Shizuku.
- Menu utama: daftar game (tambah game sendiri), tap game = XBoost in-game aktif.
- In-game: swipe dari pojok atas kiri/kanan layar -> panel (FPS, CPU/GPU, suhu, baterai, RAM, memori, app floating).
- Mode Fokus: app user lain di-force-stop + pm suspend, animasi dimatikan; semua dipulihkan saat game ditutup / Stop.
